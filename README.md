
# Ava AI Stock Analyst

An AI-powered stock research and portfolio optimisation project built with Python.

## Project Overview

This project aims to develop a stock analysis system that combines:

- Market price monitoring
- Technical analysis
- Fundamental analysis
- Stock valuation
- Risk analysis
- AI-powered news sentiment analysis
- Portfolio optimisation
